Carried over from Supplier Connect, on purpose: border-only cards (no shadows), 0.98 press-scale on buttons, semantic colors reserved for state and never doubling as the brand accent, warning-amber for banners only.
  • Unchanged: navy still carries primary buttons/links/focus rings (Supplier Connect uses orange there) — that split from the brand pair's original role is untouched.
  • Revised 2026-08-26: orange's interactive role expanded beyond logo/eyebrows/active-nav to also cover the sidebar active-item fill (a filled pill, not a thin indicator), avatar-menu item hover, category badges (e.g. Fixed RFID / Software), and secondary/ghost buttons — navy and semantic status colors are untouched by this.
  • Revised 2026-08-26: plain light gray ground (#F4F4F5) instead of the original warm near-white (#FAF8F4) — no hue borrowed from either brand color, separation from card surfaces comes from the 1px border alone.
  • Revised 2026-08-26: Inter + JetBrains Mono replace IBM Plex Sans/Condensed/Mono — self-hosted via @fontsource in the app itself (this static reference page uses a Google Fonts import purely for preview purposes). Eyebrows/labels now use Inter with uppercase + letter-spacing rather than a separate condensed face.
  • Reused as-is: the BarTender mark itself, unaltered — official logo asset, not a redraw.
