The interaction, step by step

1
Drag a Device from the left palette onto the canvas. It drops in as a Task node with one port per Channel — outbound-capable Channels on the right edge, inbound on the left.
2
Assign each unlinked port by clicking it — opens the Item Feed picker (existing library, or create new) for that Channel's input.
3
Draw a Flow Link by dragging from an output port to another Task's input port. The edge appears immediately with default delay 0–0s and no filter (implicit else) — refine it in step 4.
4
Click any edge's label chip to open its config panel (try one above): set the delay range and, when a Task has more than one outgoing edge, a GTIN/category filter per edge — exactly one edge per Task is allowed to stay the catch-all "else".
5
Run starts the simulation: items appear at each Task's fed inputs, cross to linked Tasks after their edge's delay, and generate a read event at each Channel along the way (local simulation for now — no live POST /reads yet).
Recommended library for the real build: @xyflow/react (React Flow, MIT-licensed) — it natively supports custom node components (for the port layout above), custom edge components (for the clickable delay/filter chip), and drag-to-connect between named handles, which maps directly onto Channels-as-ports rather than a generic single-handle node.
